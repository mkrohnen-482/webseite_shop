# Etappe 3 – Produkte

1. Amazon-Export nach `_ablage/amazon/`, Fotos nach `_ablage/fotos/`.
2. Import-Skript (wird gebaut, sobald der Export vorliegt) erzeugt pro Zeile `src/content/products/<slug>.md`.
3. Personalisierungsoptionen je Produkt prüfen/ergänzen – max. 8, Schema siehe PROJEKT.md.
4. Fotos optimiert nach `public/images/` (1200×1200, .webp).
5. Start mit den **Top-10**, Rest mit `active: false` vorbereiten.

**Preis-Hinweis:** Amazon kann die Buy Box unterdrücken, wenn derselbe Artikel woanders deutlich günstiger ist. Gleicher Preis, Vorteil über Versand oder Bundle.

**Fertig, wenn:** Top-10 online mit echten Fotos und vollständigen Optionen.
