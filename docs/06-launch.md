# Etappe 7 – Launch

1. **Domain** kaufen (z. B. lina-und-luksen.de).
2. Vercel → Project → Settings → Domains → Domain eintragen, DNS laut Vercel-Anleitung beim Registrar setzen.
3. `astro.config.mjs`: `site` auf die Domain setzen.
4. Stripe in den **Live-Modus**: `sk_live_…` in Vercel eintragen, neu deployen, einen echten Kauf mit kleinem Betrag testen.
5. **Google Search Console** anmelden, Sitemap einreichen (Integration `@astrojs/sitemap`).
6. **Erster Traffic – drei Kanäle:**
   - Paketbeilage bei Amazon-Bestellungen: Marke zeigen, nicht abwerben (Amazon-Richtlinien).
   - Instagram/Pinterest: Fertigungsvideos (Stickmaschine, Laser) – das verkauft personalisierte Ware.
   - Kitas, Hebammen, Geburtsvorbereitung: Gutscheinkarten.

**Fertig, wenn:** Erste echte Bestellung über den eigenen Shop.
