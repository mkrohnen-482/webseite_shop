# _ablage – hier legst du Rohmaterial ab

Nichts aus diesem Ordner geht live. Claude liest von hier und baut daraus Shop-Dateien.

| Ordner | Was rein | Format |
|---|---|---|
| `amazon/` | Produktexport aus Seller Central | .xlsx oder .txt (Lagerbericht / Kategorie-Lagerbestandsdatei) |
| `logo/` | Logo, Wortmarke, ggf. Farbvorgaben | .svg bevorzugt, sonst .png ≥ 1000 px |
| `fotos/` | Produktfotos, Dateiname = SKU oder ASIN, z. B. `B0ABC123_1.jpg` | .jpg/.png, ≥ 1200 px |
| `texte/` | Über uns, Story, FAQ, Stichworte – roh reicht | .md, .txt, .docx |
| `recht/` | Impressumsdaten, Texte vom Rechtstexte-Service | .md, .txt, .pdf |
